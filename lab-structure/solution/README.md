# เฉลยกิจกรรม Lab Basic: โครงสร้างและการทำงานของโปรแกรมภาษา C (Solutions)

โฟลเดอร์นี้รวบรวมโค้ดเฉลยสำหรับ **Lab Basic: โครงสร้างและการทำงานของโปรแกรมภาษา C** (Lab Basic: C Program Structure & Flow)

## รายการไฟล์เฉลย

### 1. `challenge_solution.c`
โค้ดเฉลยสำหรับ **กิจกรรมท้าทาย (Lab Challenge)**
- **คำตอบที่เติมลงในช่องว่างกิจกรรมท้าทาย:**
  1. **Preprocessor Directive นำเข้า stdio.h:** `#include <stdio.h>`
  2. **ประกาศ Function Prototype void showInfo():** `void showInfo()`
  3. **ประกาศฟังก์ชันหลัก int main():** `int main()`
  4. **คำสั่งแสดงข้อความ printf:** `printf`
  5. **คำสั่งส่งค่ากลับจบโปรแกรม return 0;:** `return 0;`

- **คำสั่งคอมไพล์และรัน:**
  ```bash
  gcc -o challenge_solution.exe challenge_solution.c
  ./challenge_solution.exe
  ```
