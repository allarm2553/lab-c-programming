## 📝 1. เฉลยโปรแกรมตัวอย่างที่ 2 (Fill in the Blanks) - คะแนนเต็ม 2.0 คะแนน

### 1.1 ประกาศนำเข้าห้องสมุด stdio.h
- **คำตอบที่ถูกต้อง:** `#include <stdio.h>`
- **คำตอบที่เป็นไปได้:** `#include <stdio.h>`, `#include<stdio.h>`

### 1.2 ประกาศฟังก์ชันหลัก int main()
- **คำตอบที่ถูกต้อง:** `int main()`
- **คำตอบที่เป็นไปได้:** `int main()`, `int main(void)`, `int main( void )`

### 1.3 ปิดท้ายคำสั่งแสดงข้อความ
- **คำตอบที่ถูกต้อง:** `;`
- **คำตอบที่เป็นไปได้:** `;`

### 1.4 ส่งค่ากลับจบโปรแกรมปกติ
- **คำตอบที่ถูกต้อง:** `return 0;`
- **คำตอบที่เป็นไปได้:** `return 0;`, `return 0 ;`, `return(0);`

### ซอร์สโค้ดตัวอย่างที่ 2 ฉบับสมบูรณ์ (`example2_solution.c`):
```c
#include <stdio.h>

int main() {
    printf("ตรวจสอบโครงสร้างโปรแกรมสำเร็จ");
    return 0;
}
```

- **คำสั่งคอมไพล์และทดสอบรัน:**
  ```bash
  gcc -Wall -Wextra -o example2_solution example2_solution.c
  ./example2_solution
  ```

## 🚀 2. เฉลยกิจกรรมท้าทาย (Lab Challenge Solution) - คะแนนเต็ม 4.0 คะแนน

### 2.1 บริบทโจทย์ท้าทายเชิงประยุกต์:
> ให้นักศึกษาเติมคำสั่งที่ถูกต้องลงในกล่องข้อความ [ กล่องข้อความ ] ของกิจกรรมท้าทาย เพื่อประกอบโครงสร้างโปรแกรมภาษา C ให้สมบูรณ์ ทั้งส่วน Preprocessor Directives, Function Prototype, ฟังก์ชันหลัก main(), การเรียกใช้ฟังก์ชัน และการส่งค่ากลับ (Return Value)

### 2.2 เฉลยช่องว่างกิจกรรมท้าทาย:
### 2.1 Preprocessor Directive นำเข้า stdio.h
- **คำตอบที่ถูกต้อง:** `#include <stdio.h>`
- **คำตอบที่ระบบยอมรับ:** `#include <stdio.h>`, `#include<stdio.h>`

### 2.2 ประกาศ Function Prototype void showInfo()
- **คำตอบที่ถูกต้อง:** `void showInfo()`
- **คำตอบที่ระบบยอมรับ:** `void showInfo()`, `void showInfo(void)`, `void showInfo( void )`

### 2.3 ประกาศฟังก์ชันหลัก int main()
- **คำตอบที่ถูกต้อง:** `int main()`
- **คำตอบที่ระบบยอมรับ:** `int main()`, `int main(void)`, `int main( void )`

### 2.4 คำสั่งแสดงข้อความ printf
- **คำตอบที่ถูกต้อง:** `printf`
- **คำตอบที่ระบบยอมรับ:** `printf`

### 2.5 คำสั่งส่งค่ากลับจบโปรแกรม return 0;
- **คำตอบที่ถูกต้อง:** `return 0;`
- **คำตอบที่ระบบยอมรับ:** `return 0;`, `return 0 ;`, `return(0);`

### 2.2 ซอร์สโค้ดเฉลยกิจกรรมท้าทาย (`challenge_solution.c`):
```c
#include <stdio.h>

// 1. ประกาศ Function Prototype
void showInfo();

// 2. Main Function
int main() {
    // เรียกใช้งานฟังก์ชันย่อย
    showInfo();
    
    // แสดงข้อความยืนยันความถูกต้อง
    printf("C Program Structure Validated Successfully!\n");
    
    // ส่งค่ากลับ 0 เพื่อยืนยันจบโปรแกรมปกติ
    return 0;
}

// 3. Function Definition
void showInfo() {
    printf("=======================================\n");
    printf("  C Programming: Structure Challenge   \n");
    printf("=======================================\n");
}
```

### 2.3 คำสั่งคอมไพล์และทดสอบรันบน Terminal:
```bash
gcc -Wall -Wextra -o challenge_solution challenge_solution.c
./challenge_solution
```

## 💡 3. เฉลยคำถามท้ายการทดลอง (Post-Lab Questions) - คะแนนเต็ม 3.0 คะแนน

### ข้อที่ 1: 1. อธิบายหน้าที่ของ Preprocessor Directives (เช่น #include <stdio.h>) และระบุว่าจะเกิดข้อผิดพลาดอย่างไรหากเราลืมใส่ในโค้ดโปรแกรม? (1.5 คะแนน)
- **แนวทางการตอบที่ถูกต้อง:**
  - อธิบายหลักการ ความหมาย หรือกลไกการทำงานตามหัวข้ออย่างถูกต้องตรงประเด็น
  - มีการยกตัวอย่างประกอบ หรือระบุคีย์เวิร์ดสำคัญ เช่น `preprocessor, include, ห้องสมุด, ฟังก์ชันสำเร็จรูป, error, warning`
- **เกณฑ์การให้คะแนน:**
  - อธิบายได้ถูกต้องสมบูรณ์และยกตัวอย่างชัดเจน: **1.5 คะแนน**
  - ตอบถูกแต่ขาดรายละเอียดเชิงลึก: **0.8 - 1.0 คะแนน**
  - ไม่ตรงประเด็นหรือไม่ตอบ: **0.0 คะแนน**

### ข้อที่ 2: 2. อธิบายขั้นตอนที่คอมไพเลอร์ทำการแปลซอร์สโค้ดภาษา C ตั้งแต่ไฟล์ .c ไปจนกระทั่งได้ไฟล์ผลลัพธ์ .exe อย่างสังเขป (1.5 คะแนน)
- **แนวทางการตอบที่ถูกต้อง:**
  - วิเคราะห์ข้อดี-ข้อจำกัด สาเหตุ หรือข้อควรระวังในการเขียนโปรแกรมจริง
  - มีคีย์เวิร์ดสำคัญ เช่น `compiling, linking, assembly, object, exe`
- **เกณฑ์การให้คะแนน:**
  - วิเคราะห์ได้ถูกต้อง ครอบคลุมบริบททางเทคนิค: **1.5 คะแนน**
  - ตอบได้บางส่วน: **0.8 - 1.0 คะแนน**
  - ตอบไม่ตรงประเด็น: **0.0 คะแนน**
