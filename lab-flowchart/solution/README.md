# เฉลยใบงานที่ 2 เรื่อง การเขียนผังงาน Flowchart (Solutions)

โฟลเดอร์นี้รวบรวมเฉลยสำหรับ **ใบงานที่ 2 เรื่อง การเขียนผังงาน Flowchart (Interactive)**

---

## 1. เฉลยสัญลักษณ์ผังงาน (ข้อ 2.1)

1. **2.1.1 (วงรี/ขอบมนเหลี่ยมมน):** `Terminator` (จุดเริ่มต้น / จุดสิ้นสุดของผังงาน)
2. **2.1.2 (สี่เหลี่ยมด้านขนาน):** `Data / Input-Output` (การรับหรือแสดงผลข้อมูลทั่วไป)
3. **2.1.3 (สี่เหลี่ยมข้าวหลามตัด):** `Decision` (การตัดสินใจ / เปรียบเทียบเงื่อนไข)
4. **2.1.4 (สี่เหลี่ยมผืนผ้า):** `Process` (การประมวลผล / การคำนวณ / การกำหนดค่า)
5. **2.1.5 (วงกลมเล็ก):** `Connector` (จุดเชื่อมต่อภายในหน้าเดียวกัน)

## 2. เฉลยการวิเคราะห์ IPO และผังงาน (ข้อ 2.3)

### 2.3.1 ผังงานคำนวณพื้นที่สามเหลี่ยม
- **Input (ข้อมูลเข้า):** ฐาน (Base), ความสูง (Height)
- **Process (การประมวลผล):** `Area = 0.5 * Base * Height`
- **Output (ข้อมูลออก):** พื้นที่สามเหลี่ยม (Area)

### 2.3.2 ผังงานตรวจสอบผลการสอบผ่าน/ไม่ผ่าน
- **Input (ข้อมูลเข้า):** คะแนน (Score)
- **Process (การประมวลผล):** ตรวจสอบว่า `Score >= 50` หรือไม่
- **Output (ข้อมูลออก):** "Pass" (ถ้าจริง) หรือ "Fail" (ถ้าเท็จ)

### 2.3.3 ผังงานนับเลข 1 ถึง 10
- **Input (ข้อมูลเข้า):** กำหนดค่าเริ่มต้น `i = 1`
- **Process (การประมวลผล):** แสดงค่า `i`, เพิ่มค่า `i = i + 1`, ตรวจสอบ `i <= 10`
- **Output (ข้อมูลออก):** ตัวเลข 1, 2, 3, ..., 10
