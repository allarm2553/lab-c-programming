Lab Basic: การออกแบบผังงานและการจำลองตรรกะ (Flowchart Design & Logic Tracing)

การวิเคราะห์อัลกอริทึม มาตรฐานสัญลักษณ์ ANSI/ISO การแกะรอยตรรกะด้วย Trace Table และการแปลงผังงานสู่โค้ดภาษา C

1. วัตถุประสงค์เชิงพฤติกรรม

ทักษะที่ผู้เรียนจะได้รับ (Core Competencies)

  • มาตรฐานผังงาน: เข้าใจความหมายและกฎเกณฑ์การเชื่อมต่อเส้นทางไหลของสัญลักษณ์ตามมาตรฐาน ANSI/ISO
  • การแกะรอยตรรกะ (Logic Tracing): สามารถจำลองการทำงานของผังงานทีละขั้นตอนด้วยตาราง Trace Table (Dry Run) เพื่อหาค่าตัวแปรและ Output ได้ถูกต้อง
  • การตรวจสอบข้อผิดพลาด (Debugging): สามารถวิเคราะห์และชี้จุดผิดพลาดทางตรรกะและโครงสร้างในผังงานได้
  • การแปลงสู่โค้ด (Bridge to Code): สามารถแปลงกระบวนการในผังงานเป็นโปรแกรมภาษา C ได้อย่างถูกต้องสมบูรณ์
2. สัญลักษณ์มาตรฐานและกฎการไหล (Flow Rules)
Terminator
จุดเริ่มต้น / สิ้นสุด Start / Stop / End (มีเส้นออก/เข้า 1 เส้น)
Input / Output
การรับ / แสดงผล General I/O (รับ/แสดงข้อมูลทั่วไป)
การตัดสินใจ Decision (มีเส้นออก 2 ทาง: True/False)
Process
การประมวลผล Process (คำนวณ/กำหนดค่าข้อมูล)
จุดเชื่อมต่อ On-page Connector (รวมเส้นทาง)

กฎเหล็กสำคัญของการเขียนผังงาน

  1. ทิศทางการไหลมาตรฐานคือ **จากบนลงล่าง (Top to Bottom)** หรือ **จากซ้ายไปขวา (Left to Right)** เท่านั้น
  2. สัญลักษณ์ **Decision** ต้องมีเส้นลูกศรพุ่งออกอย่างน้อย 2 ทาง และต้องมีข้อความกำกับ (เช่น `True/False` หรือ `Yes/No`) เสมอ
  3. ห้ามมีเส้น Flow Line ลอยโดยไม่มีหัวลูกศรหรือไม่มีจุดเชื่อมต่อ
