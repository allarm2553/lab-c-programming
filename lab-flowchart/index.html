Lab Basic: การเขียนผังงาน (Flowchart Design)

การออกแบบกระบวนการทำงานและผังงานตามมาตรฐาน ANSI/ISO และการวิเคราะห์ IPO Model

1. วัตถุประสงค์และเครื่องมือการเรียนรู้

วัตถุประสงค์เชิงพฤติกรรม

  • เข้าใจความหมาย หน้าที่ และมาตรฐานของสัญลักษณ์ผังงาน (Flowchart Symbols)
  • สามารถแปลงลำดับขั้นตอนการทำงาน (Algorithm) เป็นผังงานได้อย่างถูกต้องตามลำดับ
  • สามารถวิเคราะห์องค์ประกอบข้อมูลเข้า (Input), การประมวลผล (Process) และผลลัพธ์ (Output) หรือ IPO Model ได้

เครื่องมือและซอฟต์แวร์ที่แนะนำ

ชื่อเครื่องมือ ลักษณะการใช้งาน
draw.io / diagrams.net เว็บแอปพลิเคชันวาดผังงานฟรี ใช้งานง่าย Export เป็นรูป PNG/JPG ได้สะดวก
Flowgorithm โปรแกรมจำลองและทดสอบการทำงานของผังงานเชิงโต้ตอบ
สมุด / กระดาษเขียนแบบ วาดผังงานด้วยมือและถ่ายภาพแนบส่งเข้าระบบ
2. สัญลักษณ์ผังงานมาตรฐาน (Standard Symbols)

ผังงาน (Flowchart) คือรูปภาพหรือสัญลักษณ์ที่ใช้แสดงลำดับขั้นตอนการทำงานของโปรแกรมหรือระบบ ช่วยให้เข้าใจการทำงานและตรวจสอบข้อผิดพลาดได้ง่าย:

Terminator
จุดเริ่มต้น / สิ้นสุด Start / Stop / End
Input / Output
การรับ / แสดงผล General I/O
การตัดสินใจ / เงื่อนไข Decision / Condition
Process
การประมวลผล / คำนวณ Process / Calculation
จุดเชื่อมต่อ On-page Connector

หลักการวิเคราะห์ IPO Model

  • Input (ข้อมูลเข้า): ตัวแปรหรือข้อมูลที่โปรแกรมต้องรับจากผู้ใช้ (เช่น ค่ารัศมี, อุณหภูมิ F)
  • Process (การประมวลผล): สูตรคำนวณหรือขั้นตอนทางตรรกะ (เช่น การคูณ, การเปรียบเทียบ)
  • Output (ผลลัพธ์): ข้อมูลที่โปรแกรมต้องแสดงผลออกทางจอภาพ (เช่น พื้นที่วงกลม, ค่า C)
แบบรายงานผลการปฏิบัติงาน (Worksheet)
